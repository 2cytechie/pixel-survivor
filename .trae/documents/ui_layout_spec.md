# 像素幸存者 UI 排版样式规范

## 设计原则

1. **垂直分层布局**：每个界面从上到下依次为：标题区 → 内容区 → 按钮区
2. **整体垂直居中**：整个内容块在屏幕中垂直居中
3. **响应式适配**：桌面端更大更清晰，移动端更紧凑更易于点击
4. **视觉层次**：标题最大最醒目，内容次之，按钮再次之
5. **间距统一**：使用统一的间距系统，避免随意数值

---

## 间距系统

| 名称 | 桌面端 | 移动端 | 用途 |
|------|--------|--------|------|
| 大间距 (XL) | 40px | 30px | 区域之间（如标题与卡片） |
| 中间距 (L) | 30px | 20px | 按钮与内容之间 |
| 小间距 (M) | 20px | 16px | 卡片之间 |
| 紧凑间距 (S) | 12px | 8px | 文本行之间 |
| 微间距 (XS) | 6px | 4px | 文本与边框之间 |

---

| 辅助 (Caption) | 12px | 10px | Normal | 时间、难度、武器名 |

## 各界面排版规范

### 1. 主菜单 (Main Screen)

```
+------------------------------------------+
|                                          |
|           [像素幸存者]  ← H1, 金色        |
|           PIXEL SURVIVOR  ← 副标题, 灰色  |
|                                          |
|              +--------+                  |
|              |开始游戏|  ← 主按钮         |
|              +--------+                  |
|                                          |
|              +--------+                  |
|              | 成就   |  ← 次按钮         |
|              +--------+                  |
|                                          |
|    最高存活: 5:00 | 最多击杀: 100 ...    |
|                                          |
+------------------------------------------+
```

**布局规则：**
- 标题 + 按钮 + 记录文本整体垂直居中
- 标题与第一个按钮间距：XL
- 按钮之间间距：L
- 记录文本与最后一个按钮间距：L

## 响应式断点

| 设备 | 宽度范围 | 主要调整 |
|------|----------|----------|
| 手机竖屏 | < 500px | 卡片单列或双列，字体最小 |
| 手机横屏/平板 | 500-800px | 卡片双列或三列 |
| 桌面端 | > 800px | 卡片三列或四列，字体最大 |

---

## 实现要求

1. 所有间距和尺寸必须从 UIConfig 配置对象读取
2. 禁止在代码中硬编码任何像素值
3. 文本必须使用 `.setOrigin(0.5, 0)` 或 `.setOrigin(0.5)` 确保居中对齐
4. 卡片内文本从卡片顶部开始向下排列，使用相对位置（如 `cy - cardH/2 + offset`）
5. 整体内容块必须在屏幕中垂直居中
