# 响应式 UI 适配计划

## 目标
1. 手机/电脑分开处理：手机按钮文字更小、间距更紧凑；电脑按钮文字更大、更清晰
2. "像素幸存者"主标题显示在"开始游戏"按钮上方（主菜单界面）
3. 其他子界面的标题也统一显示在对应按钮/卡片的上方

## 现状分析

### 设备检测方式
- GameScene 中已使用 `this.sys.game.device.os.desktop` 判断是否为桌面端
- MenuScene 中目前没有设备检测逻辑

### 当前 MenuScene 各界面布局
- **主菜单 (showMainScreen)**：标题固定在顶部 (y=35/62)，按钮垂直居中
- **模式选择 (showModeSelect)**：标题固定在 y=95，卡片居中，按钮在下方
- **角色选择 (showCharSelect)**：标题固定在 y=95，卡片居中，按钮在下方
- **成就 (showAchievements)**：标题固定在 y=95，列表在下方，按钮在底部
- **结果界面 (ResultScene)**：标题在 h*0.15，按钮在下方

## 实现步骤

### 步骤 1：创建 UI 配置系统
在 `MenuScene` 中添加设备检测和响应式尺寸配置：
- 检测 `this.sys.game.device.os.desktop`
- 定义 `UIConfig` 对象，包含：
  - 按钮宽度、高度、字体大小
  - 卡片宽度、高度、字体大小
  - 标题字体大小
  - 间距参数

### 步骤 2：重构主菜单 (showMainScreen)
- 将"像素幸存者"和"PIXEL SURVIVOR"标题从 `create()` 移入 `showMainScreen()`
- 标题位置基于按钮区域计算，显示在按钮上方
- 应用响应式尺寸：手机按钮更小、间距更紧凑

### 步骤 3：重构模式选择 (showModeSelect)
- 标题显示在卡片上方（而非固定 y=95）
- 卡片尺寸和字体根据设备调整
- 手机端：卡片更窄、字体更小、间距更小
- 按钮位置基于卡片底部计算

### 步骤 4：重构角色选择 (showCharSelect)
- 标题显示在卡片上方
- 角色预览大小根据设备调整
- 卡片内文字对齐并应用响应式字体
- 按钮位置基于卡片底部计算

### 步骤 5：重构成就界面 (showAchievements)
- 标题显示在列表上方
- 列表项字体和间距响应式调整
- 按钮位置基于列表底部计算

### 步骤 6：重构结果界面 (ResultScene)
- 标题和按钮应用响应式尺寸
- 统计面板字体响应式调整

### 步骤 7：验证测试
- 运行项目，分别在桌面端和移动端视口下测试
- 检查所有界面的居中、对齐、字体大小是否正常
